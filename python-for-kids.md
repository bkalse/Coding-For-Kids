# 📘 Lesson 1: What is Coding?
Coding means writing instructions for the computer.

Example of an instruction:
```
print("Hello!")
```

This tells the computer to show text on the screen.

---

# 🧩 Lesson 2: Python Basics

## 1. Printing
Printing means “show something on the screen”.

```
print("I love Python!")
```

### Try it:
Change the message inside the quotes!

---

## 2. Numbers
Python can do math:

```
print(5 + 3)
print(10 - 2)
print(4 * 4)
print(20 / 5)
```

---

## 3. Variables
A variable is like a labeled box where you store information.

```
name = "MyName"
age = 8
print(name)
print(age)
```

---

## 4. Asking the User Something
```
your_name = input("What is your name? ")
print("Hello " + your_name)
```

---

# 🎮 Lesson 4: Make a Mini Game

### Guess the Number (very simple)

```
print("Guess a number between 1 and 5!")
answer = input("Your guess: ")

if answer == "3":
    print("You got it!")
else:
    print("Try again!")
```

# 🎨 Lesson 5: Draw with Turtle 🐢 (Super Fun)

Python has a built-in "turtle" that draws on the screen.

```
import turtle

t = turtle.Turtle()

t.forward(100)
t.left(90)
t.forward(100)

turtle.done()
```

Try drawing a square or a star!
